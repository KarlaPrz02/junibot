### A silly bot to ping Juni and do silly things

# What is this bot?

Junibot was created with the idea of ​​pinging Juni (a friend), as time went on more new features were implemented for various conveniences.

## Configuración del servidor

Un administrador puede usar `/configuracion` en Discord y elegir un ajuste: ver la configuración, asignar el canal de cumpleaños, entradas o salidas, o asignar el rol para nuevos miembros. Para borrar un ajuste, elige la opción «Borrar...» correspondiente. La configuración se guarda por servidor en `config.json`.

Las reacciones por rol se siguen administrando con `/reaccion`; se configuran por mensaje y `/reaccion list` muestra el canal correspondiente.
